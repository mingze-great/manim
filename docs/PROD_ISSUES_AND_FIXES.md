# 生产问题与修复清单

> 记录已经踩过的线上问题，后续遇到同类问题优先查这里。

## 1. 新版页面误打旧站 /api

现象：
- 新版页面打开正常，但请求打到 `http://<host>/api/...`
- 常见表现：聊天风格 404、latest-task 404、chat/async 404

根因：
- 新版前端构建产物不是最新版，或仍然使用了旧路径模式配置

检查：
- 新版首页 `index.html` 必须引用 `/assets/...`
- 新版页面请求必须落到 `http://<host>:3002/api/...`

修复：
- 重新按 3002 根路径模式构建新版前端
- 重新覆盖 `/opt/manim-v2/frontend/dist`

## 2. 管理员从旧站登录不跳新版

现象：
- 管理员访问根站 `/` 登录后仍停留旧版

根因：
- 旧站首页没有预分流脚本，或旧站 bundle 中跳转目标仍指向旧的 `/v2`

检查：
- 旧站首页 `index.html` 是否含预分流脚本
- 旧站 bundle 是否包含 `3002` 跳转目标

修复：
- 给旧站首页注入预分流脚本
- 旧站登录成功 / 刷新恢复 / 30 秒轮询都跳 `3002`

## 3. 旧版模型选择为空

现象：
- 生成脚本页面模型下拉显示 `No data`

根因：
- 请求模型列表时 URL 拼接错误或未带鉴权头

修复：
- 使用 `resolveBackendUrl('/api/tasks/available-models')`
- 请求带 `Authorization`

## 4. 旧版示例视频 / 视频讲解预览失败

现象：
- 提示视频不存在或下载失败

根因：
- 视频地址拼接错误

修复：
- 统一用 `resolveBackendUrl(videoUrl)`

## 5. 删除项目失败

现象：
- 我的作品删除项目返回 500

根因：
- `conversations / tasks / background_tasks` 外键仍指向旧迁移表

修复：
- 重建子表外键并指回 `projects`

## 6. 新版后台白屏

现象：
- `/admin` 白屏或控制台出现 `slice(...).map is not a function`

根因：
- 管理后台接口 URL 错误
- 前端直接假设接口返回数组

修复：
- 修正 `admin.ts` API 基址
- 对趋势数据、用户列表结果加数组保护

## 7. 新版渲染报 `Manim 未找到`

现象：
- 日志里出现 `Manim 未找到！`

根因：
- 新版渲染代码使用了错误的 Manim 路径

修复：
- 新版渲染应优先复用生产可用的 `/root/miniconda3/envs/manim311/bin/python3.11 -m manim`

## 8. 渲染页首次显示已完成 / 重新渲染

现象：
- 还没渲染就显示状态已完成，按钮是重新渲染

根因：
- 前端默认把“没有任务”误判成 completed

修复：
- 增加 `not_started` 状态
- 没有任务且没有视频时显示“未开始”
