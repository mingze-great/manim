# 讲解型视频模块需求分析与设计文档

## 1. 文档信息

- 模块名称：`讲解型视频`
- 所属版本：`v2.x` 后续新增模块
- 基线分支：`feature/v2-ui-mobile-ux-recover-3003`
- 当前规划分支：`feature/v2-next-optimization`

## 2. 背景与目标

当前系统已有三类能力：

1. 思维可视化
2. 火柴人视频
3. 公众号文章

新需求是在此基础上新增一个独立的第四类模块：`讲解型视频`。

该模块不走 `manim` 代码生成路线，目标是尽可能复刻参考视频的表现方式，即：

- 强叙事
- 强分镜
- 强字幕驱动
- 强视觉统一风格
- 轻运动镜头
- 支持情绪类、观点类、科普类等不同内容方向
- 根据文案自动生成分镜图并合成横版视频

### 核心目标

让用户输入一个主题或一段文案后，系统可以自动生成一条完整的横版讲解型短视频，具备：

1. 吸引人的开头
2. 自动生成分镜脚本
3. 自动生成分镜图片
4. 自动生成配音
5. 自动加字幕
6. 自动合成视频
7. 支持用户修改分镜文案
8. 支持用户重生单张图片
9. 支持用户替换或修改开头封面和标题

## 3. 产品定位

### 模块名称

- 最终名称：`讲解型视频`

### 模块定位

讲解型视频是一个独立一级模块，面向以下内容场景：

- 情绪表达
- 观点输出
- 认知提升
- 两性/成长/心理
- 通俗科普
- 一般知识讲解
- 任何“可被拆成分镜表达”的内容主题

### 非目标

第一版不追求：

- 复杂角色逐帧连续动作
- 高级逐镜头编辑器
- 专业时间轴
- 精细局部区域重绘
- 高复杂度角色一致性引擎

## 4. 参考视频拆解结论

基于参考视频分析，目标效果不是传统动画引擎逐帧生成，而是更接近：

- 分镜插画
- 情绪/观点叙事
- 字幕驱动
- 轻量镜头运动
- 配音 + BGM 合成

### 参考视频共性特征

1. 统一视觉风格
- 深蓝底
- 白线稿
- 局部高亮或霓虹或彩色元素
- 人物与场景以插画化方式呈现

2. 分镜节奏清晰
- 每 2 到 7 秒一个镜头段
- 全片约十几段
- 每段围绕一个句子或一个子观点

3. 动画轻量
- 不是复杂角色动作
- 主要是：
  - 缩放
  - 平移
  - 淡入淡出
  - 局部分层
  - 文字切换

4. 文案驱动极强
- 视频本质是“文案被分镜化”
- 视觉是为观点服务，不是为炫技服务

### 技术结论

最优实现路线不是 `manim`，而是：

- 文案生成
- 分镜拆分
- 插画生成
- 轻运动合成
- 字幕叠加
- 配音合成
- 成片输出

## 5. 用户核心流程

### 标准流程

1. 用户进入“讲解型视频”模块
2. 输入主题或原始文案
3. 选择风格、时长、分镜数量
4. 系统生成“吸引人的开头 + 完整分镜脚本”
5. 系统生成每个分镜的插画
6. 系统生成配音
7. 系统自动加字幕并合成视频
8. 用户预览
9. 用户按需修改：
   - 分镜文案
   - 单张图片
   - 开头标题或封面
10. 重新合成输出最终视频

## 6. 核心需求范围

### 6.1 输入能力

用户应至少支持以下输入：

1. 主题输入
- 一句话主题
- 示例：`为什么有些人越付出越得不到爱`

2. 长文输入
- 用户可直接粘贴一段完整文案、观点、科普说明
- 系统自动拆分分镜

3. 风格选择
- 情绪型
- 观点型
- 科普型
- 通用讲解型

4. 视频参数
- 分镜数量
- 时长区间
- 横版输出

### 6.2 开头生成要求

系统生成内容时，必须优先生成强吸引力开头。

#### 开头结构建议

1. 标题钩子
- 强冲突
- 强反差
- 强提问
- 强结论

2. 第一镜头视觉冲击
- 明显人物情绪
- 明显冲突道具
- 明显构图中心

3. 第一段字幕强抓人
- 让用户在 1 到 3 秒内理解核心冲突

#### 验收标准

- 开头必须有钩子
- 不允许平铺直叙直接进入正文
- 用户看前 3 秒能感知主题张力

### 6.3 分镜脚本生成

#### 目标

把主题或原始文案自动拆成 8 到 15 个分镜段。

#### 每个分镜建议包含字段

- `scene_index`
- `scene_title`
- `narration_text`
- `subtitle_text`
- `visual_description`
- `camera_motion`
- `duration`
- `transition_type`
- `hook_level`
- `emotion_tone`

#### 分镜生成规则

1. 每个分镜只表达一个清晰点
2. 文案节奏应连续推进
3. 前 1 到 3 个镜头承担抓人职责
4. 中段承担展开
5. 尾段承担升华、反转、收束

#### 验收标准

- 分镜逻辑连贯
- 每个镜头文案独立可理解
- 全片结构完整

### 6.4 分镜图生成

#### 目标

每个分镜生成一张主图。

#### 要求

1. 风格统一
- 深蓝底
- 白线稿
- 局部高亮色
- 画风一致

2. 构图明确
- 每张图有视觉主体
- 适合字幕叠加

3. 支持不同主题
- 情绪类
- 观点类
- 科普类
- 不局限某单一垂类

4. 支持单张重生
- 用户可只重生某一镜头图片

#### 验收标准

- 单张图能支撑该镜头文案
- 相邻镜头风格不跳
- 图文匹配度高

### 6.5 字幕与文案呈现

#### 需求

1. 自动字幕
- 每镜头字幕自动生成
- 支持 1 到 2 行显示

2. 字幕风格统一
- 对比清晰
- 位置稳定
- 不压坏主要视觉主体

3. 开头大标题或封面字
- 支持单独显示
- 支持用户修改

#### 验收标准

- 字幕清晰可读
- 和画面不冲突
- 开头大标题具备明显存在感

### 6.6 镜头运动与转场

#### 第一版建议支持的运动

1. 缓慢推近
2. 缓慢拉远
3. 左右平移
4. 轻微视差
5. 字幕淡入淡出
6. 镜头间交叉淡化

#### 不做

- 高级 3D 镜头
- 复杂角色骨骼动画
- 物体精细逐帧变形

#### 验收标准

- 静态图不“死”
- 视频看起来有镜头感
- 节奏和文案一致

### 6.7 配音与音频

#### 需求

1. 自动生成整片配音
2. 配音按分镜切分或按整稿生成
3. 支持背景音乐
4. 后续可扩展音色选择

#### 验收标准

- 配音和字幕基本一致
- 配音节奏与镜头时长匹配
- BGM 不压过人声

### 6.8 视频合成

#### 需求

系统应支持将以下素材合成为最终视频：

- 分镜图
- 镜头运动
- 字幕
- 开头标题
- 配音
- BGM

#### 输出要求

- 横版视频
- 可在线播放
- 可下载
- 可重新生成

#### 验收标准

- 能稳定导出成片
- 音画同步基本可接受
- 成片风格接近参考视频

### 6.9 编辑能力

必须支持：

1. 修改分镜文案
- 单镜头修改
- 修改后可重新生成后续内容或局部内容

2. 单张图片重生
- 对某一镜头单独重生
- 不影响整片其他镜头

3. 修改开头
- 修改标题
- 修改开头镜头文案
- 修改封面图或第一帧图

#### 验收标准

- 用户无需整片重做即可局部优化
- 局部修改后可重新合成

## 9. 风格控制建议

不要只靠一条 prompt。

建议分三层控制：

1. 全局风格模板
- 深蓝底
- 白线稿
- 局部高亮
- 情绪插画质感

2. 角色或场景模板
- 主角年龄、气质、发型、衣着
- 背景类型
- 画面线稿强度

3. 分镜级 prompt
- 当前镜头动作
- 当前道具
- 当前场景
- 当前情绪
- 当前构图

这样比单一 prompt 更稳定。

## 10. 技术实现建议

### 10.1 推荐路线

第一版走：
- 文案 -> 分镜 -> 图片 -> 字幕/镜头运动 -> 配音 -> 合成

### 10.2 不推荐路线

第一版不要做：
- 纯 Manim
- 复杂逐帧视频生成
- 高复杂 AI 动态角色动画

### 10.3 为什么

因为参考视频的主要价值不在复杂动画，而在：

- 分镜节奏
- 画风统一
- 情绪推进
- 文案与字幕的表达

## 11. MVP 范围

第一版必须完成：

1. 新模块入口
2. 横版输出
3. 开头钩子生成
4. 8 到 15 个分镜脚本
5. 每个分镜一张图
6. 自动字幕
7. 自动配音
8. 一键合成
9. 支持修改分镜文案
10. 支持单张图片重生

第一版暂缓：

1. 高级转场编辑器
2. 多角色一致性深控制
3. 专业时间轴
4. 多种复杂镜头模板库

## 12. 验收标准

### 功能验收

1. 用户可以创建讲解型视频项目
2. 用户可以输入主题或原始文案
3. 系统能生成有吸引力的开头
4. 系统能输出完整分镜脚本
5. 系统能生成对应分镜图
6. 系统能生成配音并合成视频
7. 用户可以改单个分镜文案
8. 用户可以重生单张图
9. 用户可以修改开头标题或封面后重新合成

### 效果验收

1. 成片风格明显接近参考视频
2. 开头有明显钩子
3. 视频节奏清晰
4. 字幕清楚可读
5. 画面不死板

## 13. 风险评估

### 高风险

1. 风格一致性不足
2. 图像质量不稳定
3. 文案拆分质量波动

### 中风险

1. 音画节奏不一致
2. 局部重生后整体风格漂移
3. 横版布局下字幕和主体遮挡

### 低风险

1. 新入口
2. 新模块分类
3. 历史作品分类展示

3. 输出比例：`横版`
4. 编辑能力：
- 修改分镜文案：需要
- 单张图片重生：需要
- 修改开头：需要
5. 开头要求：必须有吸引人的开头
